# Consumer Complaints Analysis

## Overview

This project explores financial services complaints using the 'Consumer Complaints Database' dataset. The analysis aims to investigate which financial products generate the most complaints, patterns, how have complaints changed over time.

This analysis can be particularly interesting to people who are looking to change banks or financial institutions.

## Setup

To obtain the data for this project, run the download-data.py script found in scripts/. The data will get downloaded in data/raw/.

## Dataset

- Source: Kaggle
- Geographic coverage: USA
- Time period: 1 December 2011 - 15 November 2017

## Research Questions

- Which financial products generate the most complaints?
- How have complaint volumes changed over time?
- Which issues have the highest share of disputed complaints?
- Which factors are associated with timely company responses?
- Are there differences by submission channel or region?
